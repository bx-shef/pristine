# shef.pristine — чистый интерфейс сотрудников

Модуль коробочного Битрикс24: оставляет сотрудникам в левом меню только то,
что нужно для работы. Разным отделам и людям — разный набор (профиль).
Ничего не удаляет — только скрывает; откат одной командой.

## Как работает

- **Профили** — `config/profiles.php`: какие пункты меню оставить
  (`keep`), каким отделам (по названию в структуре компании) и людям (по ID)
  какой профиль. Профиль человека важнее отдельского. Без профиля интерфейс
  не трогается. Правка профилей — через PR.
- **Применение** — PHP-консоль админки («Инструменты → Командная
  PHP-строка»):

  ```php
  \Shef\Pristine\Apply::run(dryRun: true);    // показать, кому и что поменяется
  \Shef\Pristine\Apply::run(dryRun: false);   // применить
  \Shef\Pristine\Apply::rollback();           // вернуть как было
  ```

- Меню человека — настройка ядра `intranet / left_menu_sorted_items_<сайт>`
  (`show` — пункты по порядку, `hide` — скрытые). Модуль переносит лишнее в
  `hide`, сохранив перед этим прежнюю настройку (своя настройка модуля у
  пользователя); повторный запуск ничего не меняет. Кеш левого меню
  сбрасывается тегом ядра `bitrix24_left_menu`.
- «Инструменты» портала (CRM, задачи, сайты…) включаются только для всего
  портала — по отделам их не разделить. Лишнее для всех выключает отдельный
  шаг по списку `tools_off` (инструмент целиком или раздел — «Лента»,
  «Смарт-процессы», «Аналитика» CRM…):

  ```php
  \Shef\Pristine\Tools::run(dryRun: true);    // показать, что выключится
  \Shef\Pristine\Tools::run(dryRun: false);   // выключить (с копией прежнего)
  \Shef\Pristine\Tools::rollback();           // вернуть как было
  ```

- Пункты, которых нет ни в чьей настройке меню («Сайты»), скрываются по
  списку `known`.
- Чего нет в настройках ядра — кнопка «Показать все» под меню, «Пригласить»,
  «Демо» и «Помощь» в шапке — скрывает стиль (`Chrome`, обработчик
  `main / OnProlog`) только у людей с применённым профилем. Что скрыть,
  профиль выбирает ключом `chrome` (группы `header`, `crm_kanban`,
  `crm_menu`; нет ключа — все). Пункты карточки CRM скрывает shef.agentflow.
  Модуль, уже
  установленный раньше, нужно переустановить, чтобы зарегистрировать обработчик.
- Удаление модуля возвращает меню людей и инструменты как было и уносит свои
  настройки.

Подробно про хранение меню, инструментов и кнопок в ядре —
[docs/intranet-ui.md](docs/intranet-ui.md).

## Требования

PHP 8.2+, Битрикс24 (коробка) с модулем `intranet`, `shef.options` 3.x.

## Сборка и проверки

```bash
./build.sh --check   # проверки и тесты на заглушках
./build.sh           # + архив shef.pristine.zip
./build.sh --version # версия модуля
./build.sh --notes   # примечания к выпуску (секция CHANGELOG)
```

Выпуск — workflow «Release» (по тегу `v*` или вручную от `main`): архив
`shef.pristine.zip` прикладывается к релизу GitHub.

Модуль вырос в репозитории `adminsite-standartnoby/Agentic-Workflows`
(`modules/shef.pristine/`, #276) и переехал сюда.
