# Правила модуля shef.pristine

Модуль линейки `bx-shef`: чистый интерфейс сотрудников коробочного
Битрикс24 — профили левого меню, «Инструменты» портала, лишние кнопки.

- Работа попадает в `main` только через PR (squash), в `main` не пушим.
- Перед PR: `./build.sh --check` зелёный; его же гоняет CI.
- Профили (`config/profiles.php`) правятся только через PR.
- Применять на портале клиента — только с подтверждения владельца; сначала
  `Apply::run(dryRun: true)` и `Tools::run(dryRun: true)`.
- Как ядро хранит меню и инструменты — `docs/intranet-ui.md`; названия опций
  и селекторы ядра по памяти не писать, только после замера на стенде.
- Новый файл — в `SHIP` или `KEEP` `build.sh`; `KEEP` = `export-ignore` в
  `.gitattributes`.
- Комментарии, документация, коммиты — по-русски; код — по-английски.
